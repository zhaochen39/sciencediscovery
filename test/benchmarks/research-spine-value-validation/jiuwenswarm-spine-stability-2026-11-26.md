# JiuwenSwarm Spine 组合、中断与并发验证

实验使用 WSL、JiuwenSwarm 0.2.6 和实际 ScienceDiscovery API。三个实验臂分别为原版 `d684215`、同版本候选的被测开关关闭、同版本候选的被测开关开启。受控模型用于固定行为并检查模型收到的消息。真实模型记录供方报告的用量。下表中的耗时为对应 Run 从提交至终态的墙钟时间。

## Scope 观察与 Projection 同开

受控与真实模型实验的三臂都完成。各臂都通过 `/messages` 读取五份档案、给出正确追问答案 `FROZEN/155`，并在独立短问答中给出 `14`。开启臂的 Scope 仍可查询五次原始 Shell 执行。短问答均只发起一次模型请求，无 Shell 执行。

受控模型实际收到的追问消息体为 **61,052 → 54,924 字节（−10.04%）**，历史长文本换成节点记忆，旧证据仍可从存储查询。真实网关记录了开启组一次 `scope.projection.applied`，两组关闭臂均为零次。

| 真实模型指标 | 原版 | 候选关闭 | 候选开启 | 开启相对候选关闭 |
|---|---:|---:|---:|---:|
| 追问输入 Token | 45,753 | 45,767 | 42,406 | −7.34% |
| 追问输出 Token | 7 | 7 | 7 | 0 |
| 追问总 Token | 45,760 | 45,774 | 42,413 | −7.34% |
| 三个 Run 的总 Token | 328,103 | 328,548 | 325,084 | −1.05% |
| 三个 Run 累计耗时 | 42.421 s | 44.031 s | 45.442 s | +1.411 s |
| Shell 次数 | 5 | 5 | 5 | 0 |

原始记录在 `logs/swarm-combined-20261126`，每臂目录保留 `result.json`、`driver.log` 和 `exit-code.txt`。

## 运行中断与核验后重试

受控模型的三臂各执行两种中断。第一种在 Shell 状态仍为 `running` 时发出停止命令。第二种在文件已经写入、模型尚未返回最终答复时停止 Swarm。正式复测中，六次原 Run 均以 `failed` 结束。六次 Shell 最终均为 `completed`，重试前已写入一行。三臂都在重新启动 Swarm 且适配器探测可达后提交普通新消息。六次重试均自然完成，返回 `COMMITTED`，发起零次 Shell，账本最终各有且仅有一行。

| 原 Run 到失败终态的时间 | 原版 | 候选关闭 | 候选开启 |
|---|---:|---:|---:|
| Shell 运行中开始停止 | 4.706 s | 4.265 s | 4.229 s |
| 文件写入后开始停止 | 4.482 s | 5.300 s | 4.395 s |

初轮重启等待上限为 75 秒，原版和候选关闭组都超时。复测将等待上限对齐启动脚本，并增加适配器可达校验。首次失败记录在 `logs/swarm-interrupt-20261126`，正式复测记录在 `logs/swarm-interrupt-r2-20261126`。这两种中断的共同前提是重试前已验证账本内容。命令未落盘时的补写、自动恢复和正式 `researchResume` 检查点恢复需要各自的覆盖证据。

## 新 TSV 样本与双并发

每臂先处理一份两列 TSV，再在两个会话并行处理各自的同名输入文件。逐项核对最终答案、`result.txt`、输入文件字节、Shell 归属。开启组额外核对 Scope 与各自 Shell 执行的引用。受控模型还设置了双请求到达屏障，两个并发请求都到达模型后才继续。

首轮真实模型中，候选关闭和候选开启各有一次输出将执行前说明与数字拼接，触发纯数字断言。复测的三个臂都采用显式最终结果行，并按原验收继续独立核对产物与隔离。复测在受控和真实模型下均为三臂全通过，每臂各完成三个样本。

| 真实模型指标 | 原版 | 候选关闭 | 候选开启 |
|---|---:|---:|---:|
| 三个样本的输入 Token | 550,978 | 587,893 | 550,107 |
| 三个样本的输出 Token | 1,935 | 1,993 | 1,765 |
| 三个样本的总 Token | 552,913 | 589,886 | 551,872 |
| 模型请求 | 15 | 16 | 15 |
| Shell 次数 | 8 | 8 | 7 |
| 单样本墙钟耗时 | 19.780 s | 21.833 s | 26.616 s |
| 双并发墙钟耗时 | 25.216 s | 35.248 s | 26.136 s |

候选开启相对候选关闭的三样本总 Token 减少 6.44%，相对原版减少 0.19%。三个样本均从新会话启动，日志中的历史 Projection 命中为零。请求次数和 Shell 选择也发生变化，按一次真实模型对照呈现这些波动。失败首轮在 `logs/swarm-isolation-20261126`，正式复测在 `logs/swarm-isolation-r2-20261126`。
