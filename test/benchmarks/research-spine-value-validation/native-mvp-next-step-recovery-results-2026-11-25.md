# 已验收阶段恢复的待办交接验证 · 2026-11-25

## 改动

恢复器重新校验原始输入、工作区文件和质控产物的版本，并独立复算质控。新版继续保留原始任务说明，为模型补充已验收的质控事实、下游取数所需字段以及第一项待办。完整表已经展示时，下一步是从 `site_qc.csv` 计算技术分组。展示仍待完成时，下一步先用单独的工具调用输出当前版本的完整表。此做法承接 SpineCodex 对原始轨迹和当前任务输入的区分，完整轨迹与质控表仍可供审计。

## 设计与验收

光伏用例包含 120 个合成站点和 480 条合成日观测。每组用真实模型在同一任务的质控阶段生成一个冻结检查点。捕获指令预设表格展示状态，两种状态各三组。新版、原精简版与完整历史恢复在不同进程续跑同一个冻结点，从头重跑使用同样的确定性原始输入。四个交付分支串行轮换，均有同样的表格顺序契约。直接比较新版和原精简版，用完整历史恢复和从头重跑衡量缩短上下文和避免重算的收益。

- 四个交付分支都须自然结束、五项产物独立复算通过。恢复分支的原始输入与已验收质控文件须逐字节一致，质控写入调用为零。业务请求和压缩请求分别对账，再汇总全部输入和输出 Token。
- 记录每个调用前后产物字节变化和退出码，并按工具调用 ID 对齐工具结果。仍待展示时，分组文件首次变化之前必须有另一次成功的完整表输出。完整表内容以规范化换行比较，版本仍用原始文件字节验证。
- 额外调用统计分组前无产物变化且未履行展示义务的调用，以及任何重复输出完整表的调用。同一调用同时符合两项只计一次。单个调用内部发生了多少文件读取不在该统计口径内。
- 第一次推进待办的时间从运行器启动计到成功展示待展示的完整表，或在表已展示时首次成功写入分组文件。故障后交付耗时计入检查点读取、校验、工作区复制和验收。计入捕获的耗时还包含到达质控检查点之前的执行。
- 进入第二用例的门槛为六组全部通过正确性验收，两种检查点状态各至少覆盖三组。新版相对原精简版的额外调用总数和交付耗时配对中位数均下降。新版相对完整历史恢复，首轮输入的配对中位降幅至少 15%，交付耗时的配对中位数下降。

## 验收结果

**功能验收通过，收益门槛未通过。** 新版保留为 benchmark 实验选项。首轮上下文和总 Token 的变化与交付延迟、额外工具调用的变化方向不同，详见下表。

### 受控 E2E

固定响应模型分别验证待展示和已展示两种状态。每个状态包含四个分支，共 **2/2 组、8/8 条交付**自然结束并通过独立产物验收。两种状态下，每种恢复方式的质控写入、分组前无进展调用和重复整表输出均为零。待展示组先展示再分组，已展示组三种恢复方式均直接分组。相对原精简恢复，新版两个场景的总 Token 分别从 19,551 增至 20,237、从 12,618 增至 13,172，输出 Token 相同。这是固定响应下新增交接字段的输入开销。受控模型使用估算的输入用量，收益判断以真实模型数据为准。

- **相对原精简恢复**，新版首轮输入平均增加 4.16%，全请求输入、输出和总 Token 分别下降 **16.04%、4.05% 和 15.20%**。交付时间平均下降 6.63%，配对中位下降 0.841 秒，额外调用由 **9 增至 11**，首次推进时间配对中位增加 3.236 秒。
- **相对完整历史恢复**，新版首轮输入配对中位下降 **72.38%**，超过预设的 15% 门槛。全请求总 Token 平均下降 26.10%，交付时间配对中位**增加 4.900 秒**，未通过延迟门槛。
- **相对从头重跑**，只计算故障点后的成本，新版总 Token 平均下降 **52.77%**，交付时间平均下降 **16.69%**，配对中位缩短 12.214 秒。计入故障前的成功捕获，新版整条路径平均少用 **26.06%** 总 Token，墙钟增加 **28.05%**。

### 捕获偏差与额外成本

第 3 组首次捕获提前展示了要求留待恢复后展示的完整表。捕获校验拒绝了这个检查点，当时四个交付分支均未启动。明确捕获指令后仅补跑第 3 组，四条交付共用补跑生成的合格检查点。初批执行过程中启动脚本改动导致自动汇总报 EOF，另外五组的原始结果完整，事后使用同一验收器生成了首批 5/6 的审计，再对六组做最终审计。两版汇总与失败日志均已留存，成功捕获来自两版捕获指令。

失败捕获额外耗时 **51.972 秒**，供应商报告的 3 次业务请求共 **27,191 输入 / 2,596 输出 / 29,787 总 Token**，压缩请求 0 次，业务用量与汇总对账。将这笔成本一次性归到新版部署路径的敏感性计算后，六组含捕获均值为 **72,351.83 总 Token、114.04 秒**。相对从头重跑仍少用约 20.61% 总 Token，墙钟增加约 38.58%。这是捕获失败成本完全由新版路径承担的口径，主表的含捕获指标仅纳入每组共享的成功捕获。

功能验收与两种状态覆盖均达标。额外调用和对完整历史恢复的延迟未达标，暂缓进入仪器校准复验及正式运行时接入。后续若继续改进，应优先检查首次调用的参数准备和重复探查，并用同一光伏对照验证这两项门槛。
