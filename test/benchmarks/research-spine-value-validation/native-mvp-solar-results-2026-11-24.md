# ScienceDiscovery 阶段投影诊断与光伏观测复验 · 2026-11-24

## 实现与验收口径

逐阶段诊断通过 `SCIENCE_AGENT_CONTEXT_TRACE=1` 启用。Trace 记录接收的证据和通过校验的证据数量，区分结果缺失、匹配歧义、近期保护、工具调用配对异常、预算不足、记忆不够短和候选可用，并记录可比较的原始结果与记忆的估算 Token。诊断沿用已有投影决策。历史、阶段证据和候选投影分开保留，技术参照见上一轮 [SpineCodex 机制与 ScienceDiscovery 实现对照](./native-mvp-verified-stage-results-2026-11-24.md)。

光伏是独立的合成观测用例。输入包含 120 个站点、三种技术和 480 条日观测。模型需要按站点连接两份 CSV、排除 18 条无效观测、计算归一化产出，再执行全站点与 102 个完整站点的分组比较。五件产物的验收重算全部 462 条有效观测、每个站点的均值、两份三技术汇总和报告字段。审计程序独立于模型生成的脚本，验收同时校对输入文件。模型直接输出 120 行站点质控表供后续审核，输出是本用例的审阅要求。运行器保留真实工具输出。

真实模型使用 `DeepSeek-V4.1-Flash-1017`。候选继续要求预计至少节省 1,500 个历史 Token 且达到 10%，保留最近 2 条消息。所有可比批次均允许模型自行修复后自然结束。真实 Token 来自供应商 usage，估算值用于判定候选。完整 A/B 的门槛是两组全部自然结束并通过独立验收，平均总 Token 至少下降 5%，至少三分之二的配对输入下降，平均模型轮次和工具调用都不增加。

## 校准与受控回归

一次真实校准影子运行自然结束，通过五件产物的独立验收，供应商报告 35,487 输入、2,907 输出、38,394 总 Token，7 个模型轮次、6 次工具调用。7 轮全部跳过，其中 3 轮当时没有可用的阶段闭合证据。其余轮次累积记录 3 次近期保护、6 次记忆不够短。这个分布来自本次追加的校准样本。

原 cohort 的受控 E2E 三个模式均自然结束，产物验收通过。Dynamic、Dynamic 影子、Projection 各使用 5 个模型轮次和 4 次工具调用。影子模式 1 次过门槛，模型输入实际替换 0 次。Projection 模型输入实际替换 1 次。Context 58/58，Native 与校准证据回归 56/56，Context 构建、API 及测试类型检查通过。

### 命中与回退归因

- 74 个 Projection 轮次中，26 次实际替换模型输入里的工具结果，覆盖 9/10 条轨迹，首次命中在第 4–6 轮且均早于任务结束。实际投影轮次平均节省 1,886.54 个**估算历史 Token**。该指标由 Context Estimator 计算。上表的完整任务 Token 取自模型供应商。
- 其余 48 个轮次均使用 Dynamic 路径。44 轮没有可替换的已验证阶段结果，4 轮低于绝对节省门槛。逐阶段记录显示，站点质控有 30 次候选、10 次近期保护、5 次原结果不在当前消息窗口。阶段决策可以在同一轮并存，候选数也包括被总门槛拦下的轮次。
- 每组各 9/10 次运行在签发站点质控证据的调用中输出完整质控表。Dynamic 第 3 对及 Projection 第 7 对在另一次调用输出了完整表。第 7 对 Projection 绑定的质控结果较短，所有候选最高预计只省 307 Token，8 轮均回退。这条轨迹多了 3 轮和 2 次工具调用，是整批唯一总 Token 反向的样本。

### 验收结论

**光伏用例通过预设的小流量成本门槛。** 两边独立验收及 usage 核验全通过。平均总 Token 降幅 14.06% 超过 5%，9/10 对输入下降超过要求的 7/10，平均模型轮次与工具调用都下降，并观察到实际投影。

在相同前缀上的首轮输入降幅为 13.06%，说明替换这段已验收结果可以直接减少请求输入。完整任务的 14.06% 总 Token 降幅包含模型后续执行路径的变化。此前仪器校准任务实际命中 0/72 轮，本轮也观察到耗时上升。结果支持在具备可靠阶段证据且存在大块工具输出的工作流中做限定试点，框架默认模式为 Dynamic。后续可优先复验完整审阅输出与阶段证据来自不同调用的场景，核对来源绑定后再验证成本和延迟。
